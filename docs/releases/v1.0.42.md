# v1.0.42 릴리즈 안내

v1.0.41 이후의 무기 모딩 개선과 퀘스트 검색 안내를 포함합니다.
실제 게시 여부와 다운로드 파일은 [GitHub 릴리즈](https://github.com/kidgogo1/Tarkov-Helper-Web/releases/tag/v1.0.42)에서 확인하세요.

## 주요 변경

- **부품 필터 프리셋**: ‘반동 우선 → 인체공학’, ‘인체공학 우선 → 반동’ 두 기본 버튼을 제공합니다. 2순위는 1순위가 같은 후보에 적용됩니다. 검색어·상인·가격 제한·체크 조건·정렬 순서를 이름을 붙여 저장하고 불러오거나, 확인 후 덮어쓰기·삭제할 수 있습니다.
- **모딩 화면**: 총기를 가리던 슬롯 이름을 이미지 카드와 연결선으로 정리했습니다. 장착/빈 부위/필수 부위를 구분하고 하위 부위를 선택할 수 있습니다. 부품 성능과 가격은 비교하기 쉽게 정렬하고, 기본 총기 대비 수치 변화는 막대로 보여줍니다.
- **구매 비용**: 기본 총기에 포함된 부품을 추가 구매 비용으로 중복 계산하지 않습니다. 재사용 가능한 기본 부품 수량을 반영하고, 새로 사야 하는 부품·상인만/플리만/최저가 예상 비용·필요 상인 레벨을 구분합니다. 가격이 없는 항목은 누락으로 표시하며 완전한 총액처럼 안내하지 않습니다.
- **저장·편집**: 총기 조립 프리셋과 즐겨찾기를 저장할 수 있습니다. 편집 중 실행취소/다시실행, 초기화 확인, 손상되거나 지원하지 않는 저장 자료의 자동 덮어쓰기 방지를 추가했습니다.
- **외형 미리보기(선택 기능)**: 외부 이미지 생성에 동의하고 켠 경우, 부품 변경과 각도 적용에 맞춰 조립 이미지를 요청합니다. 바로 실행 버전은 이미지 생성 중에도 지도·위치 추적 요청을 처리합니다.
- **Windows 미리보기 안정성**: 허용 범위 안의 큰 조립 요청을 잘못 거부하던 크기 제한 불일치를 수정했습니다. 잘못된 외부 응답을 거부한 후 연결 정리 오류가 발생해도 원래 실패 원인을 보존합니다. 과대 요청·응답 거부 제한은 유지합니다.
- **퀘스트 검색**: 이름의 공백·문장부호 차이를 정규화하고, 카파 필수 등 다른 필터 때문에 검색 결과가 숨겨졌을 때 원인과 해제 방법을 안내합니다.

## 알아둘 점

- 외형 미리보기는 게임의 자유 회전 3D 모델이 아니라 각도별 조립 이미지입니다. 기본은 꺼짐이며, 일부 부품·최신 아이템은 외부 서비스에서 지원하지 않을 수 있습니다. 실패·미지원 상태를 표시하며 기본 이미지를 현재 조립 외형이라고 표시하지 않습니다. 부위 연결선도 게임 모델의 정확한 3D 좌표가 아닙니다.
- 외형 생성 시 총기·부품 ID, 장착 구조, 선택 각도를 전송합니다. 게임 파일·스크린샷·로그는 전송하지 않습니다. 이미지 확대는 로컬 표시만 바꾸며 외부 생성 요청을 추가하지 않습니다. 정적 웹 ZIP만으로는 바로 실행 버전의 로컬 미리보기 API를 제공하지 않습니다.
- 모딩 부품·가격의 포함 데이터 기준은 2026-08-26입니다. 기본 총기의 현금 구매 정보는 2026-09-06에 보완했습니다. 모든 가격·재고가 실시간이라는 의미는 아니며 게임 가격과 다를 수 있습니다.
- 저장한 조립/필터 프리셋과 즐겨찾기는 같은 브라우저 프로필·접속 주소에 보관됩니다. 다른 PC·브라우저·포트로 자동 동기화되지 않습니다. 실행취소 기록은 현재 편집 세션에만 유지됩니다.
- 기본 필터 버튼을 누르면 이전 검색어와 제한 조건을 해제합니다. 저장 프리셋의 상인이 현재 부위·모드에서 제공되지 않으면 적용 전에 확인하며 저장 원본은 유지합니다.

## 업데이트와 복구

Windows 바로 실행 버전은 **설정 → 데이터 → 프로그램 업데이트**에서 확인하세요. RSA 서명·불변 릴리즈·파일 해시 검증 정책은 유지하며, 이번 버전이 모든 구버전의 업데이트 문제를 새로 해결했다는 뜻은 아닙니다.

자동 업데이트가 반복 실패하면 최신 **Direct ZIP**을 받고 기존 앱을 종료한 다음, 기존 폴더 위에 덮어쓰지 말고 짧은 새 폴더에 압축을 풀어 실행하세요. 같은 브라우저 프로필과 `http://127.0.0.1:41753/`을 유지하면 브라우저 진행도와 설정을 계속 사용할 수 있습니다. 정상 실행을 확인하기 전까지 기존 폴더와 자료를 보관하세요. 실행 중인 두 버전을 동시에 켜지 마세요.

이전 공개 버전은 [v1.0.41](https://github.com/kidgogo1/Tarkov-Helper-Web/releases/tag/v1.0.41)입니다. 필요하면 새 버전을 종료하고 보관한 이전 폴더에서 실행할 수 있지만, 이전 버전에서는 새 모딩 기능이 보이지 않습니다. 브라우저 저장소를 지우거나 ‘진행 초기화’를 누를 필요가 없습니다. 진단이 필요하면 지원 코드와 **설정 → 데이터 → 진단 기록**을 확인하세요.
