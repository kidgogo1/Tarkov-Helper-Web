Tarkov Helper 웹 바로 실행 버전

[실행]
1. TH 아이콘이 표시된 "Tarkov Helper.exe"를 더블클릭합니다.
2. 기본 브라우저가 자동으로 열릴 때까지 잠시 기다립니다.
3. 서버는 콘솔 창 없이 백그라운드에서 실행됩니다.
- "Tarkov Helper.exe"를 오른쪽 클릭하면 작업 표시줄에 고정할 수 있습니다. Windows 11에서 항목이 바로 보이지 않으면 "더 많은 옵션 표시"를 누르세요.
- 회사 PC 보안 정책 등으로 EXE가 차단될 때는 호환용 "Tarkov Helper 실행.vbs"를 사용할 수 있습니다.
- 업데이트 패키지의 RSA 서명은 파일 변조를 검사하지만 Windows 게시자 인증서와는 다릅니다. 조직의 실행 정책이나 SmartScreen이 EXE를 차단할 수 있으며 프로그램은 이 정책을 우회하지 않습니다.

[종료]
- "Tarkov Helper 종료.vbs"를 더블클릭합니다.
- 실행 파일을 다시 눌러도 서버는 중복 실행되지 않고 기존 창만 엽니다.

[Windows 시작 메뉴]
- "Tarkov Helper 시작 메뉴 등록.vbs"를 더블클릭하면 현재 사용자 시작 메뉴의 모든 앱과 검색에 Tarkov Helper가 추가됩니다. 관리자 권한은 필요하지 않습니다.
- 등록된 항목은 이 배포 폴더의 실행 파일과 전용 TH 아이콘을 사용합니다. 시작 화면이나 작업 표시줄 고정은 Windows 시작 메뉴에서 사용자가 직접 선택할 수 있습니다.
- 배포 폴더를 다른 위치로 옮기거나 새 폴더에 다시 압축 해제했다면 새 위치에서 등록 파일을 한 번 더 실행해 바로가기 위치를 갱신하세요.
- "Tarkov Helper 시작 메뉴 제거.vbs"를 더블클릭하면 Tarkov Helper가 만든 시작 메뉴 바로가기만 제거합니다. 앱, 진행도와 설정은 삭제하지 않습니다.
- 시작 프로그램에는 등록하지 않으므로 Windows 로그인 때 자동 실행되지 않습니다.

[진행도 저장]
- PVP/PVE 진행도와 설정은 브라우저 로컬 저장소에 보관됩니다.
- 항상 같은 브라우저 프로필로 접속하세요. 시크릿/인프라이빗 창에서는 진행도가 유지되지 않을 수 있습니다.
- 실행 주소는 진행도 유지를 위해 http://127.0.0.1:41753/ 으로 고정됩니다.
- 업데이트 파일과 복구 상태는 배포 폴더 밖에 보관됩니다. 같은 브라우저 프로필과 고정 주소를 사용하면 업데이트 후에도 진행도와 설정이 유지됩니다.

[프로그램 업데이트]
- 이 기능은 공개 GitHub 릴리스에 연결된 Windows 바로 실행 버전에서만 동작합니다. 일반 웹페이지 버전에서는 사용할 수 없습니다.
- 새 버전 확인은 자동으로 반복하지 않습니다. "설정 > 데이터 > 프로그램 업데이트 > 업데이트 확인"을 눌렀을 때 확인합니다.
- 새 버전이 표시되면 "업데이트 및 계속 사용"을 누릅니다. 다운로드 후 서명, 해시와 패키지 파일을 모두 검증하며, 검증 전에는 현재 프로그램을 바꾸지 않습니다.
- 검증이 끝나면 로컬 서버와 현재 탭이 자동으로 다시 연결됩니다. 일반적으로 몇 초 동안 연결이 잠시 끊기며, 큰 패키지나 느린 저장 장치에서는 검증이 더 오래 걸릴 수 있으므로 탭을 닫지 마세요. 직접 실행 파일을 다시 누를 필요가 없습니다.
- 다운로드만 끝난 상태에서 작업이 중단되었다면 "지금 적용하고 계속 사용"을 누르면 같은 자동 적용·재연결을 다시 시작합니다.
- 새 버전이 정상적으로 시작되지 않으면 이전 버전으로 자동 복원하고 같은 고정 주소로 다시 연결합니다. 실패 안내가 계속되면 "문제 해결용 실행.cmd"에서 기록을 확인하세요.
- 복구용 이전 버전 폴더는 새 버전이 정상 기동할 때까지만 유지하고 성공 확인 후 자동 삭제합니다. 백신이나 파일 잠금 때문에 즉시 삭제하지 못하면 숨김 정리 폴더로 옮겨 다음 실행에서 다시 정리합니다.
- 사용자는 Tarkov 계정, 라이선스 키, GitHub 계정·토큰 또는 별도 권한을 입력할 필요가 없습니다. 공개 릴리스를 익명으로 확인합니다.
- 업데이트 확인과 다운로드에는 인터넷 연결이 필요합니다. 업데이트하지 않아도 이미 포함된 앱과 데이터는 오프라인으로 사용할 수 있습니다.
- v1.0.4 이하 배포본은 실행 중 적용 기능을 스스로 추가할 수 없습니다. v1.0.5 바로 실행 버전만 한 번 수동으로 받아 기존 폴더 대신 사용하면, 이후 버전부터 사용 중 한 번의 클릭으로 업데이트할 수 있습니다.

[문제가 생기면]
- 실행되지 않으면 "문제 해결용 실행.cmd"를 열어 오류 메시지를 확인하세요.
- 진단 기록은 %LOCALAPPDATA%\TarkovHelperWeb의 server.log와
  %LOCALAPPDATA%\TarkovHelperWeb\app-update의 worker.log, broker.log에 저장됩니다.
- 각 기록은 새 항목까지 포함해 1 MiB가 되기 전에 .previous.log 한 개로 회전합니다. Windows 탐색기 주소창에
  %LOCALAPPDATA%\TarkovHelperWeb을 붙여 넣으면 현재 기록과 직전 기록을 함께 찾을 수 있습니다.
- 진단 기록은 외부로 자동 전송되지 않으며 토큰·nonce·인증 헤더·로컬 절대 경로는 기록 전에 가립니다.
  이 버전이 처음 기록할 때 이전 버전의 server.log, worker.log, broker.log와 각 .previous.log도 크기를 제한해 다시 가립니다.
  이 버전은 자식 PowerShell의 stdout/stderr 원문을 파일로 저장하지 않습니다. 이전 버전이 남긴
  *.stdout.log 또는 *.stderr.log를 공유할 때는 내용을 먼저 확인하거나 삭제하세요.
- 41753 포트를 다른 프로그램이 사용 중이면 그 프로그램을 종료한 뒤 다시 실행하세요.
- Windows 방화벽 창이 표시되면 공용 네트워크 접근은 허용할 필요가 없습니다. 서버는 이 PC의 127.0.0.1에서만 열립니다.
- app 폴더와 실행 파일들을 서로 분리하지 마세요. 전체 폴더는 다른 위치로 옮겨도 됩니다.

[지도 위치 자동 감지]
- 실행 중에는 Escape from Tarkov 스크린샷 폴더를 자동으로 찾습니다.
- 새 PNG 스크린샷이 생성되거나 변경되면 파일명에서 위치를 읽습니다. 이미지 내용은 읽지 않습니다.
- 스크린샷 시각 직전의 EFT application 로그에서 지도가 확인되면 그 지도로 자동 전환해 위치를 표시합니다. 로그 원문·경로·세션 ID는 브라우저에 전달하지 않습니다.
- 신선하고 명확한 지도 로그를 찾지 못한 경우에는 좌표로 지도를 추측하지 않으며, 화면에서 현재 레이드 지도를 한 번 확인해야 합니다.
- Documents, 사용자 문서 폴더와 OneDrive의 Escape from Tarkov\Screenshots 경로를 확인합니다.

[아이템 시세]
- 상단 "시세" 메뉴에서 한글 이름, 영문 이름 또는 약칭으로 검색합니다.
- PVP/PVE 전환에 맞는 릴리스 시점 시세가 앱에 포함되어 있어 오프라인에서도 검색할 수 있습니다.
- 아이템을 선택하면 이 바로 실행 버전은 json.tarkov.dev에서 해당 아이템의 최신 가격 기록만 확인합니다.
- 성공한 결과는 10분 동안 재사용합니다. 통신이 끊기면 앱에 포함된 시세 또는 최대 7일 이내의 로컬 캐시를 출처와 함께 표시합니다.
- 검색어, 퀘스트 진행도, 설정, 스크린샷 내용은 시세 서버로 보내지 않습니다. 시세는 참고용이며 게임 안의 실제 거래가는 달라질 수 있습니다.

[미니맵]
- 지도 탭에서 "미니맵 열기"를 누릅니다.
- Edge/Chrome에서는 지원되는 경우 화면 위 작은 PiP 창으로 열리고, 지원되지 않으면 페이지 내 미니맵으로 표시됩니다.
- 미니맵 안에는 지도와 현재 플레이어 위치만 표시됩니다. 화면 방식·확대율·투명도·플레이어 크기와 위치 초기화는 메인 웹의 "설정 > 화면 > 미니맵"에서 조정합니다.
- 이 "바로 실행" 버전의 Edge/Chrome 미니맵은 기본 300×300 크기의 무테·항상 위 오버레이로 고정됩니다. 잠금 또는 클릭 통과 상태에서는 브라우저 주소·창 조작 영역을 잘라내고 지도만 표시합니다.
- 위치나 크기를 바꾸려면 본 지도 화면에서 잠금을 해제하고 미니맵을 이동하거나 크기를 조정한 뒤 다시 고정하세요.
- 클릭 통과를 켜면 미니맵 창 자체를 누를 수 없습니다. 반드시 본 지도 화면의 버튼으로 클릭 통과를 해제하세요.
- 오버레이가 열린 동안 Alt + + 키로 5% 확대하고 Alt + - 키로 5% 축소합니다. 일반 키보드의 +는 Shift와 함께 누르는 키이므로 실제 조합은 Alt + Shift + = 입니다. 숫자 키패드의 +와 -도 지원합니다.
- 다른 프로그램이 전역 단축키를 이미 사용 중이면 메인 웹에 안내가 표시됩니다. 이때는 미니맵 창을 클릭해 포커스한 뒤 같은 키를 사용하세요.
- 문제가 생기면 "Tarkov Helper 종료.vbs"를 실행하세요. 미니맵의 원래 창 테두리·위치·크기를 복원한 뒤 서버를 종료합니다.
- 잠근 위치와 크기는 현재 실행 중에만 유지되며 프로그램을 다시 실행하면 저장된 위치를 자동으로 복원하지 않습니다.
- 일반 정적 웹/압축 배포에서는 Windows 네이티브 고정·클릭 통과 기능을 사용할 수 없습니다.
- 일반 정적 웹/압축 배포에서는 브라우저 밖 전역 단축키를 사용할 수 없지만, 미니맵에 포커스하면 Alt + +와 Alt + -가 동작합니다.

별도의 Node.js 설치는 필요하지 않습니다. 인터넷은 프로그램 업데이트 확인·다운로드, 선택한 아이템의 최신 시세 확인과 위키 링크를 직접 열 때 사용합니다.
