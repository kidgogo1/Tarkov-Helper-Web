Tarkov Helper 웹 바로 실행 버전

[실행]
1. "Tarkov Helper 실행.vbs"를 더블클릭합니다.
2. 기본 브라우저가 자동으로 열릴 때까지 잠시 기다립니다.
3. 서버는 콘솔 창 없이 백그라운드에서 실행됩니다.

[종료]
- "Tarkov Helper 종료.vbs"를 더블클릭합니다.
- 실행 파일을 다시 눌러도 서버는 중복 실행되지 않고 기존 창만 엽니다.

[진행도 저장]
- PVP/PVE 진행도와 설정은 브라우저 로컬 저장소에 보관됩니다.
- 항상 같은 브라우저 프로필로 접속하세요. 시크릿/인프라이빗 창에서는 진행도가 유지되지 않을 수 있습니다.
- 실행 주소는 진행도 유지를 위해 http://127.0.0.1:41753/ 으로 고정됩니다.

[문제가 생기면]
- 실행되지 않으면 "문제 해결용 실행.cmd"를 열어 오류 메시지를 확인하세요.
- 진단 기록은 %LOCALAPPDATA%\TarkovHelperWeb\server.log에 저장됩니다.
- 41753 포트를 다른 프로그램이 사용 중이면 그 프로그램을 종료한 뒤 다시 실행하세요.
- Windows 방화벽 창이 표시되면 공용 네트워크 접근은 허용할 필요가 없습니다. 서버는 이 PC의 127.0.0.1에서만 열립니다.
- app 폴더와 실행 파일들을 서로 분리하지 마세요. 전체 폴더는 다른 위치로 옮겨도 됩니다.

[지도 위치 자동 감지]
- 실행 중에는 Escape from Tarkov 스크린샷 폴더를 자동으로 찾습니다.
- 새 PNG 스크린샷이 생성되거나 변경되면 파일명만 감지합니다. 이미지 내용은 읽지 않습니다.
- Documents, 사용자 문서 폴더와 OneDrive의 Escape from Tarkov\Screenshots 경로를 확인합니다.

[미니맵]
- 지도 탭에서 "미니맵 열기"를 누릅니다.
- Edge/Chrome에서는 지원되는 경우 화면 위 작은 PiP 창으로 열리고, 지원되지 않으면 페이지 내 미니맵으로 표시됩니다.
- 이 "바로 실행" 버전의 Edge/Chrome 미니맵은 기본 300×300 크기의 무테·항상 위 오버레이로 고정됩니다.
- 위치나 크기를 바꾸려면 본 지도 화면에서 잠금을 해제하고 미니맵을 이동하거나 크기를 조정한 뒤 다시 고정하세요.
- 클릭 통과를 켜면 미니맵 창 자체를 누를 수 없습니다. 반드시 본 지도 화면의 버튼으로 클릭 통과를 해제하세요.
- 문제가 생기면 "Tarkov Helper 종료.vbs"를 실행하세요. 미니맵의 원래 창 테두리·위치·크기를 복원한 뒤 서버를 종료합니다.
- 잠근 위치와 크기는 현재 실행 중에만 유지되며 프로그램을 다시 실행하면 저장된 위치를 자동으로 복원하지 않습니다.
- 일반 정적 웹/압축 배포에서는 Windows 네이티브 고정·클릭 통과 기능을 사용할 수 없습니다.
- 브라우저 밖 전역 단축키는 지원되지 않습니다.

별도의 Node.js 설치나 인터넷 연결은 필요하지 않습니다. 위키 링크를 직접 누를 때만 인터넷을 사용합니다.
