# ADR-005: 버전형 무기 모딩 카탈로그와 총기별 기본 프리셋

## 상태

Accepted

## 날짜

2026-08-26

## 배경

무기 모딩 화면에는 모든 총기·호환 부품·슬롯·충돌·능력치·상인 가격·플리 시세가 필요하다.
이 자료를 브라우저가 실행할 때마다 외부 API에서 조회하면 통신 제한, 서비스 장애, CORS 및 버전 차이로
릴리스마다 동작이 달라진다. 또한 같은 부품이라도 총기별 기본 프리셋에서 장착된 하위 부품이 다르므로,
부품 하나에 전역 `factoryPartIds`를 합치면 서로 다른 총기의 개머리판 등이 한 구성에 섞인다.

## 결정

1. Tarkov.dev 커뮤니티의 `json.tarkov.dev` regular/PVE/영문/한글 아이템·퀘스트 자료를 릴리스 준비 시
   `pnpm data:refresh-weapon-modding`으로 가져와
   `public/data/weapon-modding/catalog.json`에 생성한다. 앱 실행 중 호환성 계산에는 외부 API를 사용하지 않는다.
2. 카탈로그는 `schemaVersion`과 `dataVersion`을 가지며, 브라우저 경계에서 ID, 숫자 범위, 슬롯, 충돌,
   가격 및 `assets.tarkov.dev` 이미지 주소를 다시 검증한다. 자료가 없거나 손상되어도 모딩 메뉴만 빈 상태로
   격리하고 퀘스트·지도·아이템 기능은 계속 동작한다.
3. 기본 부품 트리는 슬롯 ID를 포함한 `factoryPresetBuild`로 **총기별** 보관한다. 같은 레일을 서로 다른
   슬롯에 2~3개 쓰는 프리셋도 개수를 보존한다. 생성 테스트와 번들 통합 테스트에서 현재 171개 총기의
   기본 빌드 생성, 부품 개수 및 필수 슬롯 유효성을 전수 검사한다.
4. 중앙 이미지는 Tarkov.dev가 제공하는 기본 프리셋 이미지를 참고용으로 표시한다. 부품을 바꿀 때 이미지를 합성하지 않으며,
   장착 트리와 계산된 능력치가 실제 선택 상태를 나타낸다. 원격 이미지가 불러와지지 않으면 안정적인
   대체 아이콘을 표시한다.
5. 사용자 빌드는 본 앱 진행도 스키마와 분리된 `tarkov-helper-web:weapon-builds:v1`에 총기별로 저장한다.
   새 카탈로그에서도 모든 ID·슬롯·충돌 검사를 통과한 구 빌드는 `dataVersion`만 올려 복구하고,
   호환되지 않는 빌드는 기본 프리셋으로 안전하게 대체한다. 최대 32개, 1 MiB, 깊이 32, 512노드로 제한한다.
6. 플리 시세와 상인 판매 조건은 PVP/PVE 프로필별로 분리한다. 외화 상인 가격은 원본 통화와 소스가 제공한
   루블 환산값을 함께 저장해 실제 최저가를 비교하고, 퀘스트 해금 이름과 요구 레벨을 표시한다.
   플리 시세에는 프로필별 해금 레벨과 스냅샷 시각을 보관하고 UI에서 실시간이 아닌 참고가임을 명시한다.
7. 4 MB대 번들은 앱 세션에서 한 번만 읽고 HTTP 기본 캐시를 사용한다. 손상·누락·스키마 불일치는
   빈 카탈로그와 구분해 진단 기록에 남기며, Direct·정적 릴리스 ZIP에서 파일 존재를 필수 검증한다.

## 고려했지만 채택하지 않은 대안

### 브라우저에서 매번 GraphQL/JSON API 호출

릴리스와 외부 서비스 상태가 결합되고 여러 사용자가 동시에 실행할 때 통신 제한을 만들 수 있다.
데이터 갱신 시점이 명확한 생성 카탈로그가 소규모 배포와 장애 격리에 더 적합하다.

### 부품 이미지 합성으로 완성 총기 렌더링

공개 인벤토리 이미지는 동일한 좌표·원근·가림 순서를 보장하지 않아 모든 부품 조합의 정확한 합성이
불가능하다. 완성형 기본 프리셋 이미지를 기준으로 삼고, 선택 결과는 슬롯 트리로 표현한다.

### 부품별 전역 기본 하위 부품 목록

동일 부품이 여러 총기의 서로 다른 프리셋에 재사용되어 기본 하위 부품이 합쳐진다. 실제 전수 검사에서
M4A1을 포함한 19개 총기 생성이 실패했으므로 총기별 매핑으로 대체했다.

## 결과

- 릴리스마다 동일한 모딩 자료와 호환성 결과를 재현할 수 있다.
- 카탈로그는 약 4.5 MB가 릴리스에 추가되며, 중앙·부품 이미지는 Tarkov.dev CDN 연결이 있을 때 표시된다.
- 새 부품이나 밸런스 변경은 코드 수정 없이 갱신 명령과 검증을 통해 반영할 수 있다.
- 실제 변경 부품이 합성 이미지에 반영되지는 않으므로 화면에 “상점 기본 외형 · 참고 이미지”를 계속 표시한다.
