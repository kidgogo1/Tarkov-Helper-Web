# 부품 필터 프리셋

구현·검증: 2026-09-07 · v1.0.42 포함. [릴리즈 안내](releases/v1.0.42.md).

## 사용 방법

무기 모딩에서 부위를 선택하고 **필터·정렬**을 연다.

- **반동 우선**: 반동 감소가 큰 순 → 동률이면 인체공학이 높은 순.
- **인체공학 우선**: 인체공학이 높은 순 → 동률이면 반동 감소가 큰 순.
- 두 기본 버튼은 이전 검색어·상인·가격 상한·체크 조건을 해제한다. 성능 개선 체크박스를 강제로 켜지 않으므로, 두 수치가 모두 개선되는 부품만 남기는 동작이 아니다.
- **내 필터 프리셋**을 펼쳐 이름을 입력하고 **새 필터 프리셋 저장**을 누른다. 검색어, 모든 필터, 순서가 있는 정렬 기준을 함께 보관한다.
- 저장 목록에서 선택 후 **불러오기**를 누르면 현재 조건 전체를 교체한다. 선택만으로는 현재 조건이 바뀌지 않는다.
- 덮어쓰기·삭제는 확인 후 수행한다. 삭제해도 현재 적용 중인 필터는 유지된다. 직접 설정을 바꿔도 다시 저장하기 전까지 저장 원본은 바뀌지 않는다.

## 적용 범위와 안전성

필터 프리셋은 총기 조립 프리셋, 즐겨찾기, 자동 보관 중인 빌드와 별개이다. 다른 총기에서도 불러올 수 있으며 조립 구성·실행취소 기록·구매 방식·외형 생성 요청을 변경하지 않는다. 성능 정렬은 기존 계산과 동일하게 현재 빌드에서 해당 부품으로 교체한 결과의 변화량 기준이다.

상인은 기존 UI처럼 부위 및 PVP/PVE별로 다룬다. 불러오는 프리셋의 상인 판매 정보가 현재 부위·모드에 없다면 적용 전에 확인한다. 취소하면 현재 조건 전체를 유지하고, 승인하면 이번 적용에서만 상인 조건을 제외한다. 저장 원본은 보존한다. ‘현재’ 표시는 이름 선택 여부가 아니라 실제 조건의 일치 여부로 계산한다.

`tarkov-helper-web:part-filter-presets:v1`의 스키마 1 자료를 사용한다. 최대 32개, 이름 60자, 검색어 256자, 저장 자료 128 KiB이다. 같은 이름은 정규화 및 대소문자 무시 기준으로 중복을 거부한다. 미지원 스키마·필드, 손상된 저장 내용, 저장 권한·공간 문제에서 원본을 덮거나 자동 삭제하지 않는다. 저장이 안 되어도 기본 두 프리셋은 사용할 수 있다.

브라우저의 같은 접속 주소에 저장되며 계정 동기화가 아니다. 다른 컴퓨터·브라우저·호스트·포트에는 자동 전달되지 않는다. 가격 자체와 PVP/PVE 모드는 저장하지 않고 불러온 화면의 데이터를 사용한다.

## 검증 경로

- `tests/services/part-filter-presets.test.ts`: 저장·복원, 변경, 중복/한도, 손상/미지원 자료 보호, 저장 오류.
- `tests/features/part-filter-presets.test.tsx`: 두 기본 우선순위, 전체 조건 복원, 확인 취소/승인, 상인 정보 불일치, 저장 실패 시 기본 프리셋.
- `tests/features/weapon-modding-page.test.tsx`: 실제 후보 정렬과 필터 해제, 총기 빌드·편집 기록 보존.
- `e2e/part-filter-presets.mjs`: 별도 브라우저에서 실제 화면 조작, 새로고침 복원, 좁은 화면 점검. 사용자 게임과 기존 브라우저 저장 자료는 조작하지 않는다.

## 검증 결과

- 전체 단위·컴포넌트 테스트: 73개 파일, 875개 통과. 타입 검사·전체 린트·프로덕션 빌드 통과.
- 실제 M4 총구 후보에서 반동 우선의 첫 후보는 Lantac Dragon, 인체공학 우선은 Yankee Hill Phantom으로 전환됨을 확인했다. 모든 부위에서 반드시 첫 후보가 달라지는 것은 아니다. 한 부품이 두 기준 모두에서 최상일 수도 있다.
- 별도 브라우저에서 저장→초기화→불러오기→새로고침 후 복원, 확인 후 덮어쓰기·삭제, 키보드 조작, 320/768/1024/1440px 가로 넘침 및 컨트롤 경계 검사를 통과했다. 외형 생성 요청은 0회였다.
- 화면: `output/playwright/part-filter-presets-panel.png`, `part-filter-presets-priorities.png`, `part-filter-presets-{320,768,1024,1440}.png`.
- 기존 500kB 초과 JS 번들 경고와 jsdom의 외부 페이지 이동 미구현 안내는 남아 있다. 이번 작업에서 검사 규칙이나 경고를 숨기지 않았다.
- 웹 전용 테스트 서버에서 데스크톱 연결 탐지용 `client/session`, `app-update/session`, `native-overlay/session`, `local-tracker/status`의 `/api/v1/` 요청이 404를 반환한다. 기존 앱 E2E에서도 분리하던 환경 차이이며, 새 프리셋의 통신이 아니다. 이번 E2E는 테스트 원본 주소·정확한 네 경로·404 상태만 따로 기록하고, 그 외 실패 응답과 콘솔 오류·경고는 실패로 처리한다.
